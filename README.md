# aniketj.dev

Personal portfolio website for **Aniket Joshi** — Software Architect with 12+ years of experience building production systems across cloud infrastructure, distributed systems, AI, and Web3.

## About

This is the source code for [aniketj.dev](https://aniketj.dev), showcasing projects, case studies, certifications, and technical writing.

### Highlights

- **9 companies** spanning healthcare (Vanderlande), logistics (UPS), banking (JPMorgan Chase), and blockchain startups
- **6x Azure Certified** + Databricks + CKA
- **Projects** across zero-knowledge compliance (SatyaStack), artist booking platforms (ArtistsKonnect), medical logistics (Audel), blockchain monitoring (WalletWeaver), high-scale event platforms, and P2P crypto exchanges

## Tech Stack

- **Framework**: Next.js 16 (App Router, React 19, TypeScript)
- **Styling**: Tailwind CSS v4, shadcn/ui (base-nova)
- **Animation**: Framer Motion with LazyMotion
- **Blog**: MDX via next-mdx-remote/rsc
- **Contact**: Resend for email delivery
- **Deployment**: Vercel

## Getting Started

```bash
npm install
npm run dev
```
