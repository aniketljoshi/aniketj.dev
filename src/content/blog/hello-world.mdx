# Building aniketj.dev

This is the first post on the new site. I'll be writing about software architecture, cloud infrastructure, AI systems, and Web3 development.

## Tech Stack

This site is built with:

- **Next.js 15** with the App Router for server-first rendering
- **TypeScript** for type safety across the stack
- **Tailwind CSS v4** for utility-first styling
- **MDX** for this blog — markdown with React components
- **Framer Motion** for subtle animations
- **Vercel** for deployment

## Why These Choices

The goal was a fast, maintainable site that I can extend with case studies and technical writing. Next.js App Router gives me server components by default, which means most of the site ships zero JavaScript to the client.

MDX lets me embed interactive components in blog posts when needed — architecture diagrams, code playgrounds, or data visualizations.
